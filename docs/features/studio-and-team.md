# Studio & developer-team review • 0.3.0 (4)

| Area | Reproducible task | Boundary |
|---|---|---|
| Studio → Canvas | Open the included artwork sample or a local ZIP-based `.tendies`, select an embedded PNG, choose replacement artwork, and export a new copy. Reopen it and inspect the resulting layer. | Layers retain their pixel dimensions and paths; other entry contents stay unchanged, but ZIP metadata is normalised. CAML is never run. System playback/installation, full animation timeline editing, and project formats other than supported ZIPs are not implemented. |
| Studio → Cards | Edit the starter title, caption and palette; optionally crop user-selected artwork. Export the preview as a 1600 × 1000 PNG into Files. | Static art only, no real Wallet/payment operations. Text/colour choices persist locally; source photo is in memory only. |
| Studio → Signet → Apple developer team | Enter the issuer UUID and Key ID and choose a team `.p8` on your iPhone. Load registered explicit bundle IDs, eligible iOS development certificates and enabled devices. Review a named, single-target, single-device development profile request before tapping Create. Export Apple’s response locally. | Picking the key is not a network request. Loading is read-only; creation changes your Apple developer account and is never automatic. A `.p8` is an API credential, not a certificate with which to sign Mach-O code. No existing certificate is replaced/revoked. No profile request is sent by CI. Live success depends on team role, current Apple contracts, service and account limits. |

**Safety & tests:** developer API key is held in memory, never logged, synced, saved or embedded in a build. Requests use an ephemeral HTTPS session against the fixed official API host; redirects are refused. CI uses a generated throwaway P-256 key to verify the real JWT signature and claims; checks the Create Profile relationship payload and rejects invalid selections. The Canvas fixture round-trips a replacement, reads its CRC-checked contents back and checks that an unrelated entry and the entire source file were unmodified. No user wallpapers or developer credentials are included in this repo.

**Apple references:** [Create a profile](https://developer.apple.com/documentation/appstoreconnectapi/post-v1-profiles), [list bundle IDs](https://developer.apple.com/documentation/appstoreconnectapi/get-v1-bundleids), [list certificates](https://developer.apple.com/documentation/appstoreconnectapi/get-v1-certificates), [list devices](https://developer.apple.com/documentation/appstoreconnectapi/get-v1-devices).
