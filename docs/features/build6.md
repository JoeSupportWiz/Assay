# Release verification • 0.3.0 build 6

[Simulator CI (app + widget extension, fixtures)](https://github.com/JoeSupportWiz/Assay/actions/runs/44515513064) · [Previous review of the system-surface build](https://github.com/JoeSupportWiz/Assay/actions/runs/44513145701)

**Build/test evidence is not on-device acceptance.** The macOS job compiled the iOS simulator product and its WidgetKit extension, ran the listed deterministic fixtures and rendered preview screens. It did not package an IPA, modify an Apple account, test live transactions, install on a phone, or establish a device-writing engine.

## Still open
- A general iPhone-only installer that signs and installs every target end to end; signing/export alone is not installation authorization. The app and widget each need appropriate, unexpired profiles and a matching identity. Developer Program membership alone is not authority to modify protected SpringBoard settings.
- On-device whole-phone protective backup, actual system preference writes, automatic system Home Screen/widget placement and the integrated graphical Mac companion. The standalone [USB backup utility](../../Mac/usb-backup/README.md) and [File Vault](file-vault.md) solve different backup problems.
- Advanced animation timeline editing, a general icon pack publisher, richer multi-device/test-bench and community catalogue workflows, and release/update trust distribution. See [roadmap](../ROADMAP.md). No local fixture or screenshot promotes these to done.

**Quick physical test when a device build is approved:** check the app and widget bundle IDs via Signet, then check widget registration, visible Vault phase vs actual completed file restore, and privacy-lock cancellation/re-entry. Never send a `.p8`, `.p12`, device pairing record or API key in chat or an issue.
