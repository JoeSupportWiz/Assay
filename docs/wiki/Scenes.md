# Scenes

A scene saves a theme and five colours for **Assay**. Saving makes a draft. Activating changes the app. Neither action reads your system wallpaper or moves an icon.

## Try a scene and switch back

1. In **Scenes → New scene**, give the draft a name. Choose **Wallpaper match** and a palette different from the current one so the change is easy to see. Add placement notes only if you need them.
2. Tap **Save**. Under **In use in Assay**, the current appearance should still be the old one. Open the saved scene and compare **Before** with **After**.
3. Tap **Activate scene**. Back in **Scenes**, tap **Undo activation** to restore the previous theme and colours. Undo covers the latest activation only; changing the appearance elsewhere invalidates it. Deleting the draft is not an undo.

| For this result | Do this |
| --- | --- |
| Wallpaper artwork | Open the saved scene → **Export wallpaper PNG**. Save the gradient in Files and set it yourself in iOS. |
| A placement guide | **Scenes → Plan a Home Screen page**. Name the page, enter app labels in order and reserve widget space. Choose **Link to scene** if wanted, then **Save layout**. Open the saved layout’s **Placement checklist** and arrange the Home Screen by hand. |
| A reusable scene | **Scenes → Share or import a scene**. Choose a scene, then **Review export**. Check the name (always included) and optional notes (off by default), then **Export JSON to Files**. On import, preview the fields and tap **Save as new scene**. Import never activates or replaces a scene. |
