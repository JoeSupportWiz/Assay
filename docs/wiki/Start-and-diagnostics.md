# Start and diagnostics

On first launch, tap **Continue → iPhone only → Get started** for public device readings, or **Explore with a demo device** to practise. Switch later in **More → Engine**. Neither path needs a pairing file. The integrated Mac companion is unavailable in this build.

## Read the evidence

Open **Lab → Run device check**. It reads without changing anything. In **Device passport**, *Observed* means read from the selected source; *Inferred* is an explanation, not a confirmed cause; *Unknown* means the value was unavailable. In Demo, even an observed value comes from the sample device. “Nothing found” is not a hardware health certificate.

**If the clock appears stuck at 9:41:**

1. Open **Lab → Clock & Lock Screen**. Compare the large device time with the time you actually see in the status bar. Tap **My status bar shows 9:41** only if it does; otherwise enter the displayed time and tap **Compare**.
2. Repeat after at least a minute, once the device clock has advanced. The clock is measured; the status bar and any red or green Lock Screen line are **reported by you**. An imported preset log shows past selections, not current settings.
3. If only the status time differs, stop any active recording or mirroring and compare again. If the device clock itself is wrong, check **Settings → General → Date & Time**. Neither result diagnoses a damaged display.

## Preview a proposed fix

In **Lab → Diagnose a problem**, type the symptom or pick it from the catalogue. Matching is local; an AI second opinion is optional. Where offered, tap **Review the fix** and read the before/after values. **Run preview** writes nothing. Only **Apply in Demo** changes the simulated settings. Use **Lab → Undo history** to review the receipt; undo is offered only for eligible verified changes on the same engine.

Assay cannot reset protected system settings or repair physical hardware. If a line persists outside the Lock Screen, seek a hardware assessment rather than applying a preset or erasing the phone.
